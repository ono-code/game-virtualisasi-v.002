BAB 1

Konsep Dasar Sistem Operasi Linux: Desktop vs Server

Dalam dunia Teknik Elektronika Industri (TEI), sistem operasi Linux memegang peranan krusial sebagai fondasi infrastruktur sistem tertanam (embedded systems), Gateway IoT (Internet of Things), server monitoring SCADA, hingga kontroler manufaktur berbasis komputer.

A. Pengertian Kernel Linux & Distro

Linux pada dasarnya adalah sebuah Kernel—komponen inti yang menghubungkan perangkat keras (hardware) komputer dengan perangkat lunak (software). Distributor Linux (Distro) mengemas kernel ini dengan berbagai utility tools, package manager, dan Graphical User Interface (GUI).

B. Perbandingan Utama: Linux Desktop vs Linux Server

Parameter Linux Desktop (misal: Ubuntu Desktop) Linux Server (misal: Debian/Ubuntu Server)
Antarmuka (UI) GUI (GNOME, KDE, XFCE) - Tampilan Visual CLI (Command Line Interface) - Berbasis Teks
Konsumsi RAM/CPU Tinggi (memerlukan render grafis) Sangat Rendah & Efisien (Optimalkan resource)
Paket Bawaan Browser, Media Player, Office Suite SSH Server, Web Server (Apache/Nginx), Database
Tujuan di Industri Workstation desainer PCB, Pemrograman PLC Broker MQTT IoT, Server Database, Gateway SCADA
BAB 2

Instalasi VirtualBox & Pembuatan Mesin Virtual (VM)

Virtualisasi adalah teknologi yang memungkinkan satu komputer fisik (Host PC) menjalankan beberapa sistem operasi sekaligus (Guest OS) secara terisolasi. Software Type-2 Hypervisor paling populer adalah Oracle VM VirtualBox.

Mengapa Memakai VirtualBox di Pembelajaran TEI?

Siswa dapat melatih instalasi Linux Server, konfigurasi IP Static, serta pengujian remote server tanpa risiko merusak sistem operasi utama pada laptop/komputer sekolah.

A. Langkah Instalasi VirtualBox di Host PC

  1. Unduh installer VirtualBox resmi dari virtualbox.org.
  2. Jalankan file setup exe, pilih komponen default, lalu tekan Next.
  3. Pilih opsi install komponen jaringan (Network Interfaces).
  4. Unduh dan install VirtualBox Extension Pack untuk mendukung USB 2.0/3.0 dan Passthrough perangkat keras elektronika.

B. Tahapan Pembuatan Mesin Virtual (VM) Baru

Resource Hardware

Tentukan RAM (minimal 1024 MB untuk Linux Server, 2048 MB untuk Linux Desktop) dan alokasi vCPU.

Hard Disk Virtual

Buat VDI (VirtualBox Disk Image) berkisar 15 - 25 GB dengan metode Dynamically Allocated.

Mount File ISO

Masukan ISO Installer Linux (Ubuntu Server/Debian) pada menu Storage -> Optical Drive.

Mode Kartu Jaringan

Pilih Bridged Adapter agar VM mendapatkan IP lokal sekelas dengan Komputer Host untuk pengujian SSH.

BAB 3

Tata Cara Instalasi OS Linux Desktop & Server

A. Prosedur Instalasi Linux Server (Debian / Ubuntu Server)

Prosedur berbasis teks (text-based installer) yang cepat dan hemat memori:

1

Pilihan Bahasa & Region

Pilih 'English' untuk bahasa sistem utama guna mempermudah troubleshooting command.

2

Konfigurasi Jaringan & Hostname

Tentukan Hostname (misal: tei-server-01) dan alokasikan IP Static jika diperlukan.

3

Partisi Disk (Storage Partitioning)

Gunakan opsi Guided - use entire disk. Komponen partisi utama meliputi Root Partition (/) dengan filesystem Ext4 dan Partisi Swap (2x ukuran RAM virtual).

4

Seleksi Perangkat Lunak (Software Selection)

Centang paket SSH Server (OpenSSH) dan hapus centang desktop environment agar sistem murni server CLI.

B. Prosedur Instalasi Linux Desktop (Ubuntu Desktop)

Instalasi berbasis wizard grafis yang ramah pengguna:

  • Pilih opsi Try or Install Ubuntu pada menu GRUB bootloader.
  • Gunakan tipe installer Normal Installation yang menyertakan web browser dan utilities.
  • Atur lokasi zona waktu (Asia/Jakarta) serta kredensial akun user biasa dan administrator.
BAB 4

Konfigurasi Remote Server Menggunakan Tools SSH

Secure Shell (SSH) adalah protokol jaringan terenkripsi yang digunakan untuk mengoperasikan perangkat server jarak jauh secara aman melalui antarmuka baris perintah (CLI). Protokol SSH bekerja pada port default 22.

A. Persiapan pada Linux Server (Guest OS)

Pastikan layanan OpenSSH telah aktif pada server virtual Anda:

# 1. Update repositori paket

sudo apt update && sudo apt install openssh-server -y

# 2. Cek status service SSH

sudo systemctl status ssh

# 3. Cek IP Address server

ip a

B. Melakukan Remote SSH dari Komputer Host

Anda dapat menggunakan tools terminal bawaan (Command Prompt / PowerShell / Linux Terminal) atau aplikasi seperti PuTTY:

Sintaks Perintah Remote SSH: ssh username_server@IP_Address_Server

Contoh: ssh admin-tei@192.168.1.105

Langkah Pertama Saat Terhubung:

  1. Konfirmasi fingerprint keamanan SSH dengan mengetik yes.
  2. Masukkan kata sandi (password) dari user server (karakter password tidak akan tampil saat diketik).
  3. Selamat! Anda telah masuk ke dalam shell prompt server virtual.

Cheat Sheet Command Line Linux dasar

  • cd /var/www : Pindah direktori

  • ping 8.8.8.8 : Uji konektivitas internet
  • sudo systemctl restart ssh : Restart layanan SSH
  • htop / top : Monitoring penggunaan RAM & CPU
