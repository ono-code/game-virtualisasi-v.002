Dokumen media pembelajaran interaktif yang ditujukan untuk murid-murid SMK jurusan TEI dengan materi sistem operasi linux desktop dan server, virtualisasi menggunakan virtualbox, remot server menggunakan ssh dan materi dalam bentuk tek sebagai bahan bacaan murid serta diakhiri dengan uji kompetensi dengan soal pilihan ganda sebanyak 25 butir soal dengan 5 opsi jawaban dan random soal untuk setiap siswa. Aplikasi ini dibuat dengan menafaatkan AI gemini canvas dan dibuat dalam format full html. Agar murid dapat menggunakanya di perangkat yang dimiliki masing-masing maka aplikasi ini diunggah ke github. Semoga bermanfaat. terima kasih, penulis.
